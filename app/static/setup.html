Provider-Hinweise

  • Ollama (lokal): LLM_BASE_URL = http://host.docker.internal:11434/v1, API Key leer, Modell z.B. llama3.1 oder mistral.
  • LM Studio: LLM_BASE_URL = http://host.docker.internal:1234/v1, API Key beliebig (oft lm-studio), Modellname wie in LM Studio angezeigt.
  • OpenAI: LLM_BASE_URL = https://api.openai.com/v1, API Key von platform.openai.com, günstiges Modell: gpt-4o-mini.
  • Azure OpenAI: LLM_BASE_URL = https://<resource>.openai.azure.com/openai/v1, Modell = dein Deployment-Name.
  • Selbst-Hosting (vLLM etc.): LLM_BASE_URL = http://<host-ip>:<port>/v1.
